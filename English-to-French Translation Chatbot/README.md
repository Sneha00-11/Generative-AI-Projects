# English-to-French Translation Chatbot

## Overview

This project develops an interactive chatbot that translates English text into French using a pre-trained Hugging Face NLP model.

## Objective

* Translate English text into French
* Create an interactive chatbot experience
* Display translations with a typing effect

## Work Done

* Loaded the pre-trained MarianMT translation model
* Implemented English-to-French translation
* Added a word-by-word streaming effect
* Added input validation and exit commands

## Tools & Technologies

* Python
* Hugging Face Transformers
* PyTorch
* SentencePiece
* Google Colab

## Key Insights

* Pre-trained models can simplify machine translation
* Hugging Face provides easy access to NLP models
* A simple chatbot loop can create an interactive translation tool

## Learning Outcome

* Gained practical experience with NLP and transformer models
* Learned how to use pre-trained Hugging Face models
* Improved understanding of tokenization and machine translation
